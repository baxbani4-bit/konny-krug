# Экраны приложения

## 1. Первый запуск — профиль тренера
Поля: имя, телефон, адрес общего сервера, кнопка «Проверить связь».
Имя видно коллеге в строках расписания («Тренер: Ирина»).

## 2. Расписание (главный экран)
* шапка: имя тренера, состояние синхронизации, кнопки «обновить» и «профиль»;
* лента дней (2 недели, точка = есть записи);
* строки занятий: время, длительность, клиент, тренер (цветная полоса цвета тренера), тип записи,
  стоимость, статус;
* «галочка» справа: отметить выполненной (списывает занятие с абонемента) / вернуть в план;
* нажатие на строку — редактирование или удаление;
* «+» — новая запись: клиент, тренер, дата, время, длительность, тип (абонемент/разовая),
  абонемент клиента, стоимость, заметка (лошадь, маршрут).

## 3. Клиенты
Имя, телефон, сводка: активный абонемент, количество визитов, запланированные занятия.
«+» — новый клиент, нажатие — редактирование/удаление.

## 4. Абонементы
Карточка: клиент, «7 из 10», прогресс-бар, дата начала, стоимость, сколько уже использовано.
«+» — новый абонемент (всего занятий, использовано, цена, дата начала, комментарий).

## Логика списания
* Запись «по абонементу» при отметке «выполнено» увеличивает `used` в абонементе.
* Возврат в статус «запланировано» — уменьшает `used` (занятие возвращается клиенту).
* Разовая запись хранит цену в самой записи и не трогает абонементы.
